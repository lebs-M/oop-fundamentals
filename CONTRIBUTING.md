# Contributing

Welcome to the **OOP Fundamentals** workshop repository.

This repository contains workshop material used during the Peer Tutor Programme.

## Getting Started

### Step 1 – Fork the Repository

Click the **Fork** button at the top-right of this repository.

This creates your own copy under your GitHub account.

---

### Step 2 – Clone Your Fork

Clone **your own** repository.

Example:

```bash
git clone https://github.com/<your-github-username>/oop-fundamentals.git
```

---

### Step 3 – Open the Project

Open the project using your preferred IDE.

Examples:

- IntelliJ IDEA
- VS Code

---

### Step 4 – Complete the Exercises

Each week's workshop contains:

- Exercises
- Assessments

Complete the activities in your own fork.

---

### Step 5 – Commit Your Progress

Commit your work regularly.

Example commit messages:

```text
Complete Week 1 Exercise 1

Finish Week 1 Assessment

Refactor Week 1 Solution
```

Avoid messages such as:

```text
Update

Changes

Fix
```

Use meaningful commit messages that describe your work.

---

### Step 6 – Push to GitHub

Push your commits to your own repository.

```bash
git push origin main
```

---

## Workshop Expectations

- Complete all exercises independently.
- Ask questions whenever you are unsure.
- Commit your progress regularly.
- Keep your repository organised.
- Use this repository as evidence of your learning journey.

Happy coding!
