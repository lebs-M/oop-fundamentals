## Week 1 - Understanding Objects

## Workshop Overview

Many students begin writing Java code without fully understanding what an object is. This workshop revisits the fundamental building blocks of Object-Oriented Programming (OOP) by exploring classes, objects, fields, methods, constructors, and the relationship between state and behaviour.

By the end of this workshop, students should be able to identify the parts of a Java class, explain the purpose of each part, and confidently add simple behaviour to an existing object.

---

## Learning Outcomes

After completing this workshop, students should be able to:

- Explain the difference between a class and an object.
- Distinguish between state (fields) and behaviour (methods).
- Identify constructors, fields, and methods in a Java class.
- Explain the purpose of constructors.
- Add a new behaviour to an existing class.

---

## Workshop Topics

- What is a class?
- What is an object?
- Fields
- Methods
- Constructors
- State vs Behaviour

---

## Practical Exercise

Students will analyse a `Robot` class by:

- Identifying its fields.
- Identifying its methods.
- Explaining which members represent state and which represent behaviour.
- Adding one new behaviour.

---
