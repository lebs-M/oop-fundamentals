# OOP Fundamentals

Welcome!

This repository contains the workshop material developed during the Peer Tutor Programme to reinforce Object-Oriented Programming (OOP) concepts in Java.

## Purpose

These workshops are designed to help students strengthen their understanding of Java fundamentals before implementing larger software engineering projects.

Each workshop contains:

- Learning objectives
- Workshop notes
- Practical exercises
- Solutions
- Facilitator notes
- Supporting resources

## Workshop Schedule

| Week | Topic |
|------|------------------------------|

## Goal

Help students understand object-oriented thinking before writing code.
